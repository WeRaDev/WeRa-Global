# Architecture Decision Records (ADR)
This directory stores architecture and policy decisions for the umbrella repository.

## Purpose
ADRs provide durable context for why decisions were made, what alternatives were considered, and how to validate outcomes.

## File naming convention
- Format: `NNNN-short-title.md`
- Example: `0001-umbrella-development-foundation.md`

## Status model
- `Proposed`
- `Accepted`
- `Superseded`
- `Deprecated`

## How to create a new ADR
1. Copy `0000-adr-template.md`.
2. Use the next sequential number.
3. Fill all sections concisely.
4. Link related docs, tasks, and follow-up decisions.
