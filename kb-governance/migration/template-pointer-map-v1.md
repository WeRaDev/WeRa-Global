## Pointer format
Each domain repository `templates/README.md` should include:
1. Link to canonical domain template in `kb-governance`.
2. Link to canonical naming policy.
3. Link to temporal governance routing policy.
4. Note that local copies are prohibited unless approved by three-entity governance.
