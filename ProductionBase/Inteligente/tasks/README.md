# Inteligente task system
Use this directory for sprint-ready and traceable work items.

## Lifecycle
`Backlog -> Ready -> In Progress -> Review -> Validated -> Done`

## Required fields per task
- Problem statement
- Scope and non-scope
- Acceptance criteria
- Dependencies
- Validation plan

## Files
- `backlog.md`: prioritized task inventory
- `comet-audit-discovery-interview-agent5.md`: audit-only browser handoff for the existing route and Agent 5
- `sprint-template.md`: weekly sprint planning template
