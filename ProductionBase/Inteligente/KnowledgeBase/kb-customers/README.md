# kb-customers

## Purpose
Canonical domain folder for customer segments, named client dossiers, and go-to-market.

## Structure
- `docs/gtm/` — segment and ICP documents
- `docs/clients/` — named client dossiers (internal); start with `incity.md`

## Authoring policy
- Canonical authoring happens in this folder tree.
- Changes must include the metadata/provenance contract from `../templates/KB-Domain-Document-Template-v1.md`.
- Cite `../../Resources/Documents/Research/` files as evidence wherever possible.
- Named client dossiers may hold internal-only contact fields; strip PII before any public case use and do not commit raw client media binaries.
