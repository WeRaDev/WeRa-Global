# Poly-Robot Skills
Use this directory for project-specific Warp skills that automate repeatable workflows.

## Available skills
- `qa-agent.md`: code-quality + security + UX QA procedure for PR validation.

## Skill authoring standard
Each skill should include:
- Trigger conditions
- Expected inputs
- Step-by-step execution instructions
- Verification criteria
- Expected outputs
- Failure modes
