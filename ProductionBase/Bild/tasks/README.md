# Bild task system
Use this directory for sprint-ready and traceable work items.

## Lifecycle
`Backlog -> Ready -> In Progress -> Review -> Validated -> Done`

## Required fields per task
- Problem statement
- Scope and non-scope
- Acceptance criteria
- Dependencies
- Validation plan

## Files
- `backlog.md`: prioritized task inventory
- `sprint-template.md`: weekly sprint planning template
