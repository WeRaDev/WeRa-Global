# Bild skills
This directory stores project-specific skills used by human and AI contributors.

## Recommended initial skills
1. `repo-orientation`
2. `task-intake`
3. `implementation-plan`
4. `quality-gate`
5. `release-readiness`
6. `retro-capture`

## Skill format
Each skill should define:
- name
- intent
- trigger_conditions
- required_inputs
- procedure
- validation
- expected_outputs
- failure_modes
- handoff_notes
